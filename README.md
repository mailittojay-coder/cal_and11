# CASIO fx-82MS Android 11 App

Ready-to-build Android Studio WebView project configured for **Android 11 (API 30)** (`minSdk = 24`, `targetSdk = 30`, `compileSdk = 30`) with offline-capable `app/src/main/assets/index.html` and Android 11 WebView CSS fallbacks.

## Build APK in Android Studio
1. Open this folder (`CasioFx82Calculator`) in **Android Studio**.
2. Wait for **Gradle Sync** to finish.
3. Click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
4. Install the generated `app-debug.apk` on your Android 11 phone.
